# Convenient Cursor

현재 탭에서 가장 가능성이 높은 채팅 입력창을 찾아 커서를 옮기는 Chrome/Edge 확장 프로그램입니다. Gemini처럼 `textarea` 또는 `contenteditable` 기반 입력창을 쓰는 웹 채팅에서 동작합니다.

## 설치

1. Chrome에서 `chrome://extensions`, Edge에서 `edge://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `convenient cursor` 폴더를 선택합니다.

## 사용

- Chrome 툴바에 고정한 아이콘을 클릭하면 확장 프로그램이 켜지거나 꺼집니다.
- 주황색 아이콘은 켜짐, 회색 아이콘은 꺼짐 상태입니다. 상태는 Chrome을 다시 열어도 유지됩니다.
- 켜진 상태에서 아래 단축키를 누르면 채팅 입력창으로 커서가 이동합니다.
- Windows/Linux: `Alt+L`
- macOS: `Option+L`

단축키가 다른 프로그램이나 확장과 겹치면 Chrome의 `chrome://extensions/shortcuts` 또는 Edge의 `edge://extensions/shortcuts`에서 바꿀 수 있습니다.

확장 프로그램은 단축키를 누른 순간에만 현재 탭에서 입력 요소의 위치와 이름 관련 속성을 확인합니다. 입력된 메시지는 읽거나 저장하거나 전송하지 않습니다.

브라우저 설정 페이지, 새 탭, 확장 프로그램 스토어 등 브라우저가 스크립트 실행을 금지한 페이지에서는 동작하지 않습니다.

## 문제가 있을 때

- 단축키가 반응하지 않으면 확장 프로그램의 단축키 설정에서 키가 배정되어 있는지 확인합니다.
- 아이콘이 회색이면 클릭해서 주황색으로 켭니다.
- 여러 입력창이 있는 페이지에서는 화면에 보이는 입력창 중 채팅 관련 이름을 갖고 있고 화면 아래쪽에 가까운 요소를 우선합니다. 엉뚱한 곳으로 이동할 수 있습니다.
- 닫힌 Shadow DOM이나 일반적인 입력 요소를 사용하지 않는 편집기는 찾지 못할 수 있습니다.
